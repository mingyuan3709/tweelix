# Tweelix

一个面向原版生存的轻量客户端辅助模组，由 [ming_yuan](https://space.bilibili.com/388406072) 开发。

A vanilla-focused lightweight client-side utility mod.

[![Minecraft](https://img.shields.io/badge/Minecraft-1.21.11-green.svg)](https://www.minecraft.net)

---

## ✨ 功能 | Features

| 功能 | 说明 |
|------|------|
| 🎯 **准星复制** | 一键复制准星指向的方块/实体/物品的名称、注册名、坐标和标签 |
| 👁️ **观察者模式** | 限制访客打开容器/破坏方块/攻击实体等操作，适合服务器参观 |
| 💬 **命令提示** | 输入命令时展示参数说明和补全描述 |
| 📸 **自由相机** | 灵魂出窍观察周围，支持夜视和手部渲染 |
| 🏺 **考古保护** | 防止误破坏可疑的沙子/沙砾方块 |
| 👥 **隐藏跨队名称** | 按 F1 切换隐藏其他队伍的玩家名牌 |
| 📐 **Litematica 按钮** | 在 Litematica 菜单中添加快捷打开原理图文件夹的按钮 |

## 🔧 依赖 | Dependencies

- **MaLiLib** — 配置系统（必需）
- **Fabric API** — Fabric 平台（仅 Fabric）
- **ModMenu** — 模组菜单集成（Fabric，可选）

## 🛠️ 构建 | Build

```bash
./gradlew build
```

构建产物位于 `fabric/build/libs/` 和 `neoforge/build/libs/`。
